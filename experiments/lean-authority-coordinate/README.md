# Lean authority-coordinate micro-verifier

This experiment exhausts the two pure authority-coordinate predicates still mirrored by source-token checks.

It executes the live TypeScript functions for:

- all 16 combinations of execution-authority advancement guards;
- all 64 combinations of receipt coordinate guards.

The Lean kernel independently owns the error precedence and accepted condition for both surfaces.

A deliberately flipped accepted case is the negative control.

The intended deletion is the `executionAuthorityAdvanceError()` and `receiptAuthorityError()` source-text inspection in implementation-transition refinement, not the production predicates themselves.
