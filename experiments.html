authority-storage-decomposition

supported

Question. Can Overcenter factor durable project authority into immutable content-addressed fact objects plus a separately linearizable authority-head CAS without changing project semantics?

Claim. For the bounded treatment, semantic fact payloads can live in an independently addressed immutable object store while Git stores only one fact-id pointer per authority revision and supplies exact-head CAS. The composed store preserves the DurableFactStore contract, matches the monolithic Git kernel's logical transitions, fails closed when an authoritative fact object is missing, and admits exactly one winner under an eight-process same-head race even though losing immutable objects remain published but unreachable.

Result. At exact revision 7546e2b058c8be80faebaa8900a684b794275af3, the split store matched monolithic Git kernel semantics, kept authority commits fact-id-only, admitted exactly one winner in an eight-process same-head race, left seven losing fact objects unreachable, reconstructed from a copied object replica, and failed closed when an authoritative fact object was missing.
